# Coinzio booking — static preview

A self-contained preview of the appointment booking page, published for review only.
Availability is generated in the browser and the submit button shows a sample confirmation;
nothing is sent, stored, or booked.

View it at:
https://htmlpreview.github.io/?https://raw.githubusercontent.com/coinzio/coinzio-booking-preview/main/single.html

For a cleaner URL, enable GitHub Pages for this repository (Settings → Pages →
Deploy from a branch → main → /), which serves https://coinzio.github.io/coinzio-booking-preview/.

The working application (Express + MySQL + Google Calendar) lives in the private
`coinzio/coinzio-shopify-theme` project.
